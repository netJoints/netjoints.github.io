Even Frugality

An AI-assisted hotel finder that turns travel-cost discipline into a practical product experience: compare options, parking details, and availability while protecting administrator operations.

Open private repositoryView architecture

Use case

Event travelers need a fast way to compare hotel options, parking details, and availability while making cost-conscious decisions without adding administrative overhead.

How it solves it

A browser search experience calls protected serverless APIs, normalizes provider responses, caches results, and separates public search from admin workflows.

Architecture

The design separates inputs, orchestration, AI assistance, and human verification. Secrets and environment-specific identifiers belong in runtime configuration, never in this page or source control.

Software stack

Firebase Hosting, Cloud Functions, Firestore, Node.js, provider adapters, validation, caching, and notification flows.

Source-controlledTestableObservableLeast privilege

AI and AgenticOps

AI can assist with query normalization and recommendation explanations, while AgenticOps schedules refreshes, monitors provider health, and keeps secrets in managed runtime configuration.

Technical operating model

Ingest
Accept structured inputs and normalize them.
Reason
Retrieve approved context and produce a bounded plan.
Verify
Apply guardrails, human review, and evidence checks.

Public search remains narrow; administrative routes require runtime authentication and provider credentials are never committed.
