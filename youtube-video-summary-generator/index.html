YouTube Summary Generator

A local-first tool that turns a YouTube video's transcript into a summary, key takeaways, blog post, LinkedIn post, or X thread using Ollama models, with no cloud APIs and no cost.

Open source repositoryAI Projects

Pain point

Long videos are slow to review, and sending transcripts to cloud AI services adds cost and privacy concerns.

Solution

Fetch the transcript, cache it locally, and stream a formatted result from a local model through a CLI or a localhost web UI. Output is cleaned so it is safe to paste into the YouTube description box.

Architecture

  1. YouTube URL
  2. Transcript fetch with fallbacks
  3. Local cache
  4. Ollama streaming
  5. Copy as text or Markdown

Software stack

PythonOllamayoutube-transcript-apiLocal web UIGit

AI and AgenticOps

Inference stays on the user's machine. Model choice is explicit, transcripts are cached for repeatability, and the web server binds to localhost only.
